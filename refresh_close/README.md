# 临赛滚动战绩

这一版把近期表现、地图战绩和禁选的观察窗口向前推进。每届使用首阶段开赛日前最后一个完整自然日；本次新加坡观察到北京时间 2026 年 11 月 21 日之前，最后纳入的公开比赛日期为 11 月 19 日。日期按存档中比赛开始日（UTC）核对。新开关只改变这些近期特征；VRS 的赛前原始基准、临近期积分选项、已拟合的胜负模型系数，以及轻重赛制权重仍有各自的来源日期。

| 上海 2024 | 11-06 → 11-29 | 28 / 26 | 54 | 16 |

135 场新增比赛均有实际双方首发五人、完整逐图比分和七步禁选。赛制、完整图池和同队至少三名首发重合决定是否纳入。至少一支参赛队出现即可，同一场两队都属于参赛阵容时只算一场。上海的 54 场中有 53 场来自本届 RMR 资格赛。各行均为公开来源覆盖的子集。赛区数据及特征完整度口径各有独立的时间戳。

## 三类特征

- **近期表现及回合优势**。用旧窗口的逐日历史复现发布版 16 支队伍的八项统计，再把窗口向前移至临赛日，删除超出 90 天的陈旧数据，加入新比赛。仅在两方当场实际五人都能与该场之前的 Valve 积分榜按三人核心唯一匹配时，才用其积分差计算超预期表现和回合优势。新比赛的预期胜率斜率和回合差斜率沿用原快照；新数据只覆盖部分参赛队，避免重新拟合全赛场的标尺。新增的比赛比分来自可核实的比赛页面存档，能匹配独立逐图表时再对照首发。
- **分地图实力**。在新的 90 天窗口内同时使用原有地图证据和有合格赛前积分的新增场次。继续按对手积分、三人核心重合度、地图样本量和 45 天半衰期计算。滚动后会同时新增和剔除比赛，因此窗口内总图数可以下降。
- **禁选偏好**。重算窗口内所有合格的同赛制、同七图池禁选，为每一步仅累积动作发生当时仍可选的地图机会数。缺少对手积分的已核实禁选仍可进入禁选模型，对手积分不能改变比赛曾经禁了哪张图。

`observations.json.gz` 按场保留数据出处、两队首发、地图和比分、禁选步骤，并记录通过三人匹配的赛前积分与对应名单。`events.json` 为前端汇总，列出按队样本及每届新比赛原文示例。历史场次的公开资料为事后收集；入模事实按当时已经结束的比赛和此前公布的榜单裁切。此目录未读取各届 Major 赛后胜负来构建模型输入。

## 来源与复核

历史七步禁选和每张图的五人来自 [hltvy 固定存档](https://github.com/zugzugs/hltvy/tree/1a00ba2893a63646f0d940e626b6da95d342a187)，新加坡来自 [Griffin 11 月 20 日固定快照](https://github.com/Griffinxaxa/scrape-hltv-data/tree/f5e3e90fb56fef8adc19bd5e5e898d2741d0ff58/2026-data/archive)。阵容交叉核对使用 [Ektarr v11](https://www.kaggle.com/datasets/ektarr/counter-strike-pro-matches/versions/11)。比赛前积分取 [Valve 官方历史榜](https://github.com/ValveSoftware/counter-strike_regional_standings)，2024 年原始地区榜与全球榜定位见 `history24/build.py`，近年榜原始提交见 `datajob/build_features.py`。输入文件 SHA-256 在原始归一化器、`prepare.py` 和相应数据说明内固定。

从项目根目录复核已封存的数据：

```sh
OPENBLAS_NUM_THREADS=1 python refresh_close/build.py --check
node refresh_close/check.cjs
```

如持有相应的原始数据文件，可由以下命令独立重建首发、比分和积分匹配。2024 年排名目录使用 `YYYY-MM-DD-region.md` 文件名，近年月榜路径结构与 Valve 仓库一致。Griffin 目录应含五个由上游脚本校验哈希的 CSV 文件。

```sh
python refresh_close/prepare.py --historic results.json.gz --griffin griffin_csv --games cs2_all_tiers_games.csv --historic-rank-dir historic_ranks --monthly-rank-dir valve_rankings --check
```
