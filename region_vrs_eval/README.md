# 赛区排名实力的独立对照

冻结哥本哈根、上海、奥斯汀、布达佩斯与科隆各自的首阶段输入和阵容。每届对照使用同一份实力、模拟引擎、种子和填卡方法，仅开关 `regionVrs`。三对设置分别以原近期表现、原近期表现加跨区线下赛校正、临赛综合策略为起点。三组均在胜负模型之后模拟整届瑞士轮，手动锁定场数为零。

按实际对阵的种子、赛前战绩和当年赛制，对 165 场比赛分别计算 Brier、对数损失及胜方正确数，另统计欧洲、亚洲、美洲之间的每一组对局。每个具名赛区组合的胜率均从 `firstRegion` 一方视角计算。组内平均预测与实际胜场数可衡量整体偏高或偏低；Brier 逐场考核概率，在不同强弱组合上两种结论可能不一致。赛区沿用各届存档中核实的首发所属地区。

固定发布种子 33719 验证实际 2/6/2 十格卡、对应的三档命中，并比较 0–3 概率前二、前四、前六覆盖的真实全败队。再用原有 30 组随机数做完全配对的整卡稳定性对照。每组用 12,000 条训练路径选卡、独立 12,000 条路径评分；临赛综合设置在候选不同时增加独立的 12,000 条配对路径选卡。若可与上一版整个胜率矩阵及阶段共享状态逐字匹配，先复算固定种子的卡片、16 队全部结果概率、0–3 分解和选卡门槛，再复用其余 29 个种子的已核验记录。其余矩阵重新运行全部 30 组。

| 起点 | 开关 | 实际命中 | 过关届数 | 0–3 命中 | 单场 Brier |
| --- | --- | ---: | ---: | ---: | ---: |
| 原近期表现 | 关 / 开 | 20 / 23 | 2 / 3 | 2 / 2 | 0.22976 / 0.22722 |
| 含原跨区校正 | 关 / 开 | 21 / 22 | 3 / 3 | 2 / 2 | 0.22793 / 0.22750 |
| 原临赛综合 | 关 / 开 | 20 / 22 | 2 / 3 | 1 / 2 | 0.22880 / 0.22820 |

表中实际命中分母 50 格，过关分母 5 届，全败命中分母 10 格。原近期表现加入赛区 VRS 后，在相同五届上更换模拟随机数，过关届数有 11 组增加、19 组持平。五届真实比赛里，亚洲对欧洲 9 胜 19 负，对美洲 16 胜 12 负。模型分别把亚洲平均预测胜率从 43.3% 调到 38.3%，从 48.1% 调到 45.9%。后者进一步偏离实际胜率。分组样本只有 28 场，五届均属赛前重建，换随机数衡量的是模拟的稳定性。

汇总及逐届结果在 `report.json`。完整的逐场概率与实际胜方、卡片选择和种子敏感性结果在 `diagnostics.json`。新加坡前瞻只在 11 月 21 日生成一次，记录当时的完整矩阵、实际输入散列、队员名单、十格卡、各队战绩分布、两步全败风险及实现文件散列。运行以下命令可在构建后的站点复核。

```sh
node region_vrs_eval/check.cjs --check
node region_vrs_eval/freeze.cjs --check
```
