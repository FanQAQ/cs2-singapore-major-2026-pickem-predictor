# 扩大选卡搜索的五届对照

在项目根目录运行 `node research_cards/check.cjs --check` 可逐项复核 `report.json`。去掉 `--check` 会重新生成报告。

比较对象是现行的 2／6／2 三起点局部搜索与额外 24 个起点的同类搜索。两者都以整卡在 12,000 条训练路径上命中至少五格的次数为首要目标，过关次数相同时比较命中格数总和。扩展搜索把原版卡保留为候选，从预先固定的洗牌序列开始，每步评估不同类别的两队互换，直到没有更好的单次互换。每届评估了约 1.02 至 1.08 万张不同卡，这是一项有界对照。全部合法卡共有 10,090,080 张。

单场胜率、瑞士配对规则、比赛模拟和留出计分均复用生产版本。固定随机种子 33719；五届均使用相同的 24 个额外起点。选择两张卡后，再在同一组独立的 12,000 条路径上逐条计分，最后与历史赛果对照。每届的过关率都是模型模拟值；实际过关届数单列。

五届仅布达佩斯换卡，两张卡实际均中五格。五届留出过关率的平均值从 32.575% 变为 32.570%，实际均为 20/50、两届过关。本轮实验没有显示扩大搜索的收益。

全卡穷举的公开实现可参见 [lshhhhhhh/cs2-pickem-monte-carlo](https://github.com/lshhhhhhh/cs2-pickem-monte-carlo)。
