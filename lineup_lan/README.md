# 首发五人与国际 LAN 出场记录

这个视图同时回答两件事：现役选手各自打过哪些已核实的国际线下系列赛，以及本届五人共同参赛多少次。每名选手按比赛实际登场名单归属，可以带上自己转会前的经验。队伍的共同出场另按同侧阵容重合人数判断。

## 赛事范围

各届取与赛区模型一致的赛前截止日，向前看 180 天。使用相同的非 Major LAN 档案，排除 Major、RMR 和 MRQ。每场均有双方实际登场五人，当天之前 60 天内的 Valve 快照可将双方唯一匹配到至少三人重合的赛区阵容。若某赛事中已核实的比赛覆盖两个或更多赛区，归入国际 LAN。同一国际 LAN 的两个同区对手也各算一次出场；仅当具体对阵的双方赛区不同，才另加一场跨区记录。

以年度及赛事名分组，用整份源档案中观察到的首场及末场日期核对比赛已处于窗口内。首日早于窗口、末日晚于赛前截止的赛事不计。源档案对赛区和日期的覆盖有限。网页列出的起止为该届实际纳入的最早和最晚比赛，零样本表示缺少通过这些审计规则的记录。

## 按阵容和选手归属

每场始终用两边各自的五人去匹配本届首发，按系列赛 ID 去重。对一个目标队伍，一侧重合至少三人时记核心共同出场，五人全同再记完整阵容共同出场。一个队的系列赛数只记一次。

当一名现役选手登场而同侧阵容只与本届重合一人或两人时，只增加该人的出场记录和“其他阵容”计数。这个字段包含原俱乐部、同一俱乐部的旧阵容或临时混编。“同场”均指同一方共同参赛。四个经过核实的昵称别名沿用原近期表现模型。

作为辅助参照，每场用赛前双方实际阵容的 VRS 差计算所在队预期胜率 p = 1/(1+10^(−积分差/400))。若胜负为 y，累加 y−p，在分母加入五场中性样本后得到“所在队的超预期胜率”。同一五人共同出赛时，这部分战绩由五个人共享。缺少可评比分资料时显示空值。此项只在资料面板展示。
