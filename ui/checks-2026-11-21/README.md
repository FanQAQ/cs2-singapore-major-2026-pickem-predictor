两种宽度都实际完成了以下操作。

- 打开推荐卡，核对全胜 2 队、普通晋级 6 队、全败 2 队。打开「单格概率」后十队均显示所在栏位的概率。点击「整卡过关率」可打开整卡模拟说明，点击「历史命中」将焦点送到回测区。手机版十个换队按钮高度均至少 44 像素。
- 在推荐模型的「模型设置」中从新默认填法切换至「过关率优先」，五届总命中从 27/50 回到 23/50；切回后完整复现新加坡十队与 27/50。两种填法在发布种子都为 3/5 届过关。
- 点队名，选择另一位置的队伍，确认手动卡出现，恢复推荐后核对十队与原卡一致。
- 切换到决策树，在设置中调整近期表现特征，等待五届回测完成。侧栏切换到「决策树 · 当前自选特征」，显示 20/50、2/5 届。恢复决策树配置，再切回推荐模型，原卡复现。
- 展开历史赛事的数据说明。进入对阵推演，核对五轮列坐标从左至右递增。指定首场胜者，检查两队分别进入下一轮的 1–0 与 0–1 组。清除赛果后返回完整推荐卡。
- 推荐卡、概率展开和瑞士轮界面均无整页水平溢出。窄屏通过对阵图内部横向滚动查看后续轮次。

HTTP 桌面和手机测试均观察到 `history-worker.js` 和 `alternatives-worker.js` 启动。离线模式同样完成了五届历史回测。三次浏览器流程均无页面脚本异常。本组手机验证覆盖模拟视口，不涉及实体手机或公网端到端测量。
