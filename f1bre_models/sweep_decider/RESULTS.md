# 地图 ML 对第三轮全胜对局的判断改善了科隆

三届开发用 Major Stage 3 共有六场 2–0 对 2–0。仅将这些对阵的 BO3 胜率改用赛前地图 ML，Brier 分数从 **0.2065 降到 0.1718**，对数损失从 **0.6000 降到 0.5044**。额外三场赛事的六场同类对局，两项误差反而从 0.2596、0.7119 升至 0.2898、0.7773。[逐场胜率](report.json)

| 三个快速种子，原预测 → 只改全胜对局 | 第一组 | 第二组 | 第三组 |
| --- | ---: | ---: | ---: |
| 奥斯汀 Stage 3 | 3 → 3 | 5 → 3 | 5 → 3 |
| 布达佩斯 Stage 3 | 3 → 2 | 3 → 2 | 3 → 2 |
| 科隆 Stage 3 | 2 → 4 | 3 → 5 | 3 → 5 |
| 三届合计过关 | 0 → 0 | 1 → 1 | 1 → 1 |

科隆的两组过关与奥斯汀的两组失分对应。三场外部赛事共九张快速预测，实际命中均与对照相同。本试验止于快速筛查。每组 2,000 条选卡路径、4,000 条独立核分路径；正式默认成绩使用原发布预算。新加坡三阶段均未使用赛果。[登记方案](PROTOCOL.md) · [各组预测](cards.json)

从仓库根目录执行 `node f1bre_models/sweep_decider/lock.cjs` 和 `node f1bre_models/sweep_decider/score.cjs`。程序逐路径校验原模拟终局、两种方法所遇的全部全胜对手，并核对 198 场历史对阵和实际发生的 12 场全胜对决。卡托维兹使用 ESL 的比分与实时排名配对。
