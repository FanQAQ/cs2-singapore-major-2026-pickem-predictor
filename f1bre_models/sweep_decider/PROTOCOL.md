# 在 2–0 组单独使用赛前地图 ML

固定正式推荐的前两轮胜率、八个晋级候选、两个全败位、模拟种子及配对规则。仅在第三轮两支 2–0 队伍相遇时，用各自赛前冻结的地图 ML 胜率替换推荐模型的 BO3 胜率。原因是三届 Major 中的两次未过关，在选对同一组八队里的全胜位置时都有机会达到五格。地图 ML 在此使用七图概率、阵容及地图历史，原权重已冻结。本实验不重新训练。

用同一随机数重放两套模型的五轮对阵。两套第二轮结束时的战绩和第三轮对手必须完全一致。各自按本套路径中“晋级后以全胜结束”的比例，在同一组八队中选择两支全胜队。另抽独立路径，分别评价两张卡。原模型的每条终局路径必须与生产引擎逐位相同。按实际赛果确认的两场 2–0 对局计算 Brier 和对数损失，每场地另报整卡及全胜位。

先用奥斯汀、布达佩斯、科隆，每组三个固定种子，各 2,000 条选卡路径和 4,000 条核分路径。至少两组多过一届且总命中持平或上升，才扩大预算。阿斯塔纳、卡托维兹、布加勒斯特三场全 BO3 作为外部诊断，逐场公开；它们先前已参与其他方法的复核。若候选具备升级希望，再使用新的外部场地。
