# 同核心往届全胜表现能否帮助安排两个 3–0？

三个 Stage 3 的实赛全胜队有重复。这个观察来自开发样本，因此曾经全胜的队名直接参与选队会造成事后偏差。本实验对所有队使用相同规则，只读取比目标开赛更早结束的 Major 最后一个瑞士阶段。2024 年的最后瑞士阶段为 Stage 2，2025 年起为 Stage 3。每队最多在每届继承一份记录，历史五人与本次五人须直接重合至少三人，同一届不按组织名称跨阵容继承。

筛出实际晋级的同核心历史队伍。每届记录“实际是否 3–0”减“当时推荐模型的晋级条件下全胜概率”。历史概率用固定主种子、12,000 条赛前模拟路径计算。当前路径中的条件全胜率加上历史残差和除以（8＋该核心有效晋级届数），8 是每阶段晋级席数。裁剪到 0 至 1，在原八个晋级候选中取前两名。历史无人匹配时保留当前概率。两种方法共用同一套单场胜率及全部模拟路径，BO1、BO3 误差不变。

在三届 Stage 3 及已研究过的三个外部赛场分别记录实际过关、总格数、3–0 命中、入围八队条件下的 Brier、逐队历史来源和调整前后的卡。先用三个原定种子的小预算计算。若至少两组多过一届、总格数不降，才扩大到 30 个种子。还要检查删去贡献最多的一支队后是否依然有收益。开发场地与既有外部诊断不能单独证明新默认方案的独立效力。
