# 只换两队能修复科隆，跨届过关数持平

先用正式推荐与地图 ML 各选一份十格预测，只在两边有分歧的队伍中交换两个位置。按两套模型模拟时各自损失的过关次数选择换位，五格门槛、赛制和单场胜率始终相同。[登记方法](PROTOCOL.md)

| 快速筛查，原预测 → 换位后 | 主种子 | 第二组 | 第三组 |
| --- | ---: | ---: | ---: |
| 奥斯汀 Stage 3 | 3 → 4 | 5 → 3 | 5 → 3 |
| 布达佩斯 Stage 3 | 3 → 2 | 3 → 2 | 3 → 2 |
| 科隆 Stage 3 | 2 → 4 | 3 → 5 | 3 → 5 |
| 三届过关数 | 0 → 0 | 1 → 1 | 1 → 1 |

科隆三组都换了 Falcons 和 Spirit。后两组使科隆过关，也使奥斯汀原来过关的预测各丢两格。三个外部场地中，卡托维兹两组从 3 格升至 5 格，阿斯塔纳三组均过关，布加勒斯特仍为三个 3 格。停止扩样。[实际比分](report.json) · [候选换位及独立路径得分](cards.json)

复算时依次运行 `node f1bre_models/disputed_swap/lock.cjs`、`node f1bre_models/disputed_swap/score.cjs`。每种模型各用 2,000 条路径起草预测、4,000 条选换位、4,000 条独立审计。快速对照和网站正式配置使用不同模拟预算。
