# Stage 1 全败风险

每条瑞士轮路径按当届种子、交手史和对手战绩重新排下一轮。某队要以 0–3 淘汰，先须在前两轮 BO1 中均负，再输掉 0–2 组的 BO3。在同一批路径中记录这两个事件，可将全败概率拆开：

`P(0–3) = P(0–2) × P(0–2 组再负 | 已经 0–2)`。

比赛进入第三轮时，四支 0–2 队伍形成两场对阵。每条路径只在此处增加进入 0–2 组和对手的计数，赛果确定后给败方增加全败计数。汇总与现有队伍战绩概率使用同一批路径（通常是 12,000 条选卡路径和 12,000 条评估路径）。所以每队全败路径计数除以总数，会精确复现队伍概率表里的 0–3 概率。用户指定胜负后，分解随当前赛果条件重算。零条路径进入 0–2 组时，再负条件概率为空。

`CS.run(...).tailRisk[i]` 以赛事种子顺序给出总路径数、进入 0–2 的条数、全败条数、三个概率和可能对手。对手表的遇到概率是在已到 0–2 的路径中与该队对阵的比例，再负概率是在已与该队对阵的路径中落败的比例。表内样本数是模拟次数，不能作为真实交手场数。两项概率的模拟误差来自同一批随机路径，样本数量与模型训练数据覆盖是两种不同的信息。

`CS.tailRanking(tailRisk,actual?)` 按全败概率递减排序，同值按原种子次序。提供含两支真全败队的阶段赛果时，返回真全败队的风险排名、前二／前四／前六覆盖数，以及直接选末两号种子的命中数。已发布近期表现模型和主随机种子下，五届首阶段的前二、前四、前六分别覆盖十支真全败队中的 2、5、8 支；直接选末两号种子覆盖 5 支。这是历史对照，不是用户选卡时的硬性种子规则。

## 同一届共享的状态

启用已通过赛前检验的地区与阵容模型时，胜率矩阵可附带十六支队的状态尺度。该尺度以胜算对数为单位。每队在每条路径开始时等概率抽取一个正、负号，乘上该队尺度，贯穿整届；比赛的状态差为两队取值之差。对每组队伍和 BO1/BO3 分别求截距，使平均四种符号组合时的胜率与输入模型在浮点精度内一致。状态改变的是同队在本届不同轮次之间的关联。条件模拟若锁定已有结果，按已锁比赛的似然精确更新所有 65,536 种队伍符号配置的权重，再推演后续比赛。未锁定时直接均匀抽取十六个符号。没有尺度或全为零时沿用原随机序列和静态胜率。

`CS.pairedPassSample(matrix,n,seed,locks,expectedCard,passCard)` 用给定独立随机流对两张既定卡成对计分，返回两张卡都达标、只有期望卡达标、只有过关卡达标及两张都未达标的路径数。它使用与上述风险表相同的配对、赛制、锁定结果及状态处理。

在项目根目录运行 `node tail_risk/check.cjs` 可复核路径守恒、条件分解、动态对手、已锁赛果、单队状态的解析解、五届原版卡片与此前公布的名次覆盖。
