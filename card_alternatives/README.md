# 接近等价的 3–0 换位

当前推荐卡有两个 3–0 格、六个普通晋级格。网页逐一比较这两档之间的十二种互换，其余八格固定。利用原模拟的评价路径预筛，选择对过关率影响绝对值最小的一组。只有差值落在 ±1.5 个百分点内、两队换位前后都仍有命中可能、模拟中确实有路径能区分两卡时，才进入独立复核。若两组完全相同，优先选择种子序靠前的一组。

复核从相同对局胜率、已指定赛果和瑞士轮规则重新抽样。每条路径同时评分两卡，用换位卡是否过关减原卡是否过关得到 −1、0 或 1。独立随机数与推荐卡的训练、评价及稳健选卡随机数分开。先看十万条路径，若区间尚与 ±1 个百分点的边界相交，再增加到四十万条。两个预设检查点各使用双侧 97.5% 经验 Bernstein 区间，通过并集界得到至少 95% 的同时覆盖率。整个区间落入 ±1 个百分点时展示提示。候选在独立样本上不合格即结束，此轮不会另试其他队。这里的覆盖率指给定模型的模拟抽样，真实赛事的模型误差须用其他赛事检验。

复核在后台运行，本地离线网页在无法使用 Worker 时分批让出界面线程。每份模拟结果的建议可复用。新加坡两种模型的默认结果提前复核，同时保存无候选的情况。仅在没有指定任何赛果、完整 BO1／BO3 矩阵、整阶段状态参数、种子与原卡的 SHA-256 均匹配时读取。运行 `node card_alternatives/freeze.cjs --check` 可从发布的赛事输入独立重建。用户另行编辑的卡或整阶段已经结束时不显示。两队互换由使用者决定。

旧默认「近期表现＋赛区 VRS」的历史复核中，上海的 FURIA／Liquid 调位符合提示条件。科隆的 B8／BIG 符合条件，赛后能多得两格的 GamerLegion／BetBoom 未被选为候选。运行 `node card_alternatives/check.cjs` 可核对历史赛果、复核区间、实际对阵锁、用户手动卡和缓存。
