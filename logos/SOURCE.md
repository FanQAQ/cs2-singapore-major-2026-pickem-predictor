# 战队图标来源

四届第一阶段共 64 个参赛席位。每个席位在 manifest.json 中通过当届的战队名称对应一张本地 PNG，队名和标识都保留。credits.json 按图片列出战队、原图和来源页面。

多数标志来自 FragCharts 的赛事页与战队图集；Complexity 和 OG 取自 Aut-sep 维护的队标库。新加坡的 GOSH、Imperial 和科隆的 Sharks 使用各自赛事在 CS2 内发布的战队贴纸，保留赛事装饰，以显示该届的战队身份。新加坡 PVISION 在数据中使用 PARIVISION 名称，两者共用队徽。

图片裁除外围透明空白，按原宽高比缩小。部分白色及浅色标志外增加细阴影，在浅色界面中仍可辨认。视觉素材仅用于识别参赛战队；相应品牌和图像的权利属于原权利人。
