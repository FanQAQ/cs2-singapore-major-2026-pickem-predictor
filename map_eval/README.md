# 地图禁选候选策略的赛前检验

冻结选手名单、比赛记录、有效图池和基础实力后，对 16 支参赛队的 120 种两两组合分别估计 BO1 和 BO3 胜率。对照组使用现有的实力与近期表现策略。候选组在完全相同的特征设置上开启真实地图禁选和分地图实力。历史数据以每届开赛前的快照为界。比赛结果仅用于重放真实赛程和计分。

五届首阶段分别有 20 场 BO1 和 13 场 BO3。Brier 分数和对数损失越低，赛前概率与实际胜负越接近。另列基础模型给热门队 60% 至不足 70% 胜率的 BO1；两种策略共享同一批对局。覆盖统计区分 120 种潜在配对与真实发生的比赛，按 BO1 和 BO3 记录双方或单方选禁证据、回退原因以及最终胜率真正改变的场数。各策略的 `coveredOnly` 在同一批有可用禁选和分图样本的比赛上另算概率评分。

每种策略用相同随机种子 33719。先用 12,000 条瑞士轮路径选择过关率优先的十格卡，再用独立的 12,000 条路径评价。卡片按当届真实结局核对。五届总计 10 个全胜名额、30 个普通晋级名额和 10 个全败名额。普通晋级仅计 3–1 和 3–2。缺少选禁证据并导致回退时，两张卡的相同成绩只能验证回退逻辑。

在项目根目录执行以下命令。

```sh
node map_eval/check.cjs --check
node map_eval/freeze.cjs --check
node map_eval/stability.cjs --check
```

第一条命令复核五届逐场、整卡和覆盖数值。第二条命令复核 2026 年 11 月 21 日在新加坡开赛前封存的候选预测。封存包括每队三档概率、卡片、两种赛制的两两胜率、覆盖状态、算法与输入哈希。网页默认策略的原封存保留供比较。

第三条命令使用上一版已固定的 30 组随机数，对同一组五届赛事再次选卡。两种模型按随机数逐组配对，报告列出整卡过关届数变好、持平和变差的次数。30 组重复使用相同的赛事，刻画的是随机选卡的波动。主要结果仍按种子 33719 计算。

五届真实对局中，地图证据使 78/100 场 BO1 和 57/65 场 BO3 的概率发生变化。BO1 的 Brier 分数从 0.23966 变为 0.23891，BO3 从 0.21452 变为 0.21397。固定种子下，候选的全胜、普通晋级和全败分别命中 3/10、16/30 和 2/10 格；对照组分别为 3/10、15/30 和 2/10。奥斯汀从四格变为五格，其余四届总格数相同。结果体现了相同五届历史比赛上的变化，下一届的独立记录是新加坡封存预测。

同一组五届比赛换用 30 组预设随机数后，按种子配对的过关届数有 4 组上升、18 组相同、8 组下降，平均由 2.50 届变为 2.33 届。平均总命中由 21.50 格变为 20.93 格。固定种子的奥斯汀额外一格没有形成重复模拟下的稳定整卡提升。
