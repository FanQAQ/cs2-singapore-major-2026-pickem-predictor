在奥斯汀、布达佩斯、科隆的 59 场 BO3 上，使用赛前真实禁选记录使 Brier 从 **0.239706 降至 0.239546**。三个阶段分别计算也都略有下降。但用网站默认种子 33719 填卡，三届的十个选位一格都没改变，仍是 **5、2、2 格，1/3 届过关**。未见足以上调正式推荐的整卡收益。[逐届卡、比分与误差](summary.json)

## 科隆与外部赛事

科隆 120 种对阵中，66 对有双方禁选资料、48 对只有一方、6 对回到原胜率。科隆实际 33 场均有部分可用证据。最大改动是 Natus Vincere 对 Legacy 的胜率从 57.35% 到 57.96%，不足以改变固定种子的十个选位。另一种只看地图出场频率的方法在科隆反而增大误差。当前数据只够解释部分对局，未解决科隆整卡只有两格的问题。

独立的 EPL 第二阶段按该赛事自己的实时评分配对、BO3 禁选顺序重放。实际 33 场中，Astralis 击败 FaZe 的赛前概率从 55.16% 变为 57.59%。真实禁选的 BO3 对数损失从 0.718066 降至 0.714695，30 组种子里原卡与两个候选均为 5/10。它是另一场已结束的赛事，采用赛前 VRS 基线，不能加入正式 Major 的三届分母。[EPL 首发、赛制与赛果](../epl_transfer/README.md)
