# BO3 自选图兑现

同一个阵容在同一张地图上，有时是自己选，有时是对方选或留作决胜图。本特征衡量这两类局面的表现差，并学习它与下一场整个 BO3 胜负的关联。

**输入。** 从版本固定的 HLTV 禁选档中取得明确的 Ektarr 比赛编号，核对日期、实际选图名称及己方当场五人，再从逐图比赛档获取结果及比赛日前的 Valve 双方积分。一次己方选图能确证该 BO3 的其他已打地图都由对方选择或留作决胜。没有明确自选记录的系列不参与这组对照。每届只使用截至快照日过去 90 天、在当届地图池内的记录。数据与许可见 [禁选档](../map_veto_data/README.md) 与 [逐图档](../map_strength/README.md)。

**队伍估计。** 每张图的残差是实际胜负减去 VRS 系列胜率隐含的单图胜率。历史五人至少有三人与目标阵容相同，权重乘以重合比例的平方和 45 天半衰期。每张同时有自选和可确认非自选记录的地图分别求两组平均残差之差，用两组权重和的乘积除以两者之和加权，再在分母加入 3 个中性有效对照。只在某个角色出现的地图可以展示其自选战绩，但不能估计角色差异。这一差值也可能是非自选图表现较弱所致。

**估计与预测。** 在每届快照日前逐日重放有五人、赛制和系列胜方可核验的比赛。预测该日样本时，队伍自选图特征与基础 VRS 斜率均只读取更早日期的比赛。对已结束的本期及历次冻结窗口样本，使用 VRS 对数几率作偏置，拟合相对于原胜率的增量系数，并为两边资料覆盖不对称增加一个有正则化的干扰项。系数允许正负，正则化精度分别为 1 和 4，各限于正负 2。样本只要一方可比较即可用于估计。正式预测只在两个对手都能做同队同图比较的 BO3 上使用双方差值乘以系数。BO1 和无同图对照的对阵保留所选模型原胜率。
