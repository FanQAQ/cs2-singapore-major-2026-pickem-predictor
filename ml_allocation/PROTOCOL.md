# 地图 ML 的胜率与八队晋级后的分栏

2026-11-21，接续已发布的 F1bre 模型研究。此前正式 Stage 3 的地图 ML 固定推荐卡依次是 4、3、5 格。问题是已经选对的晋级队里，把全胜和普通晋级分配得更准，能否带来更多 5/10。以下比较在计算本轮候选的卡分前确定。

1. 三届真正举办的 Major Stage 3 作为开发样本。五届 Stage 2 用作跨阶段对照，单列。EPL S21、S22、S23 的第二阶段采用真正的八直邀加八晋级和官方实时配对。它们分别已用于其他研究。另选此前未用于本项目选卡的 Elisa Invitational Spring 和 Fall 2024 Main Swiss。选取春、秋两届的依据为主办方在赛前公布相同的 8+8 和五轮全 BO3，并可取得同期比赛资料。外部赛不计入 Major 正式过关数。[春季官方说明](https://elisaesports.com/2024/04/05/elisa-invitational-spring-2024-main-swiss-viewers-guide/)
2. 对每项比较固定两个单场模型。Major 取已封存的本站推荐概率与完整地图 ML，外部用赛前 VRS 与相同规范的赛前地图 ML。比较三种填法。第一种是现行推荐。第二种固定第一种的八支晋级队和两支 0–3，仅在这八队中决定哪两支列为 3–0。在既有分组法的边际概率下，按「3–0 减普通晋级」降序取前两名，这在固定八队时最大化两栏期望命中。第三种完全沿用既有分组法，同时选择三栏队伍。组内按赛前 VRS 排名，从赛前已结束的其他 Major Stage 2/3 学同入场通道的战绩分布；权重与原实现相同。没有更早资料时，使用纯模拟边际。全程固定参数。
3. 同一胜率、同一种子下，三种填法共用 12,000 条选卡路径和独立的 12,000 条评价路径。测试线上主种子和原有 30 个配对种子。在 Major、ESL 使用原赛制模拟并核对原卡。若 Elisa 的同分组内抽签规则无法在赛前资料中证实，以官方公布的首轮为起点，在其后各轮分别使用同战绩内均匀抽取无重赛配对，以及按赛前 VRS 强弱高低配对的敏感性设定。两类模拟均须逐条保留其限制。若官方种子序列缺失，现行填法的种子位按赛前 VRS 排序估计。即使某类模拟恰巧重合实战配对，也不据此选择规则。规则未完全核实时，该赛事仅检验方案迁移，不能单独支持更改正式默认。
4. 开赛后临时换队的，按原队身份给锁盘时的卡打分。整队由不同核心取代时，选原队的那一格没有命中；再单列「若该位置改为继承替补队成绩」的敏感性分数。行政判胜计入正式赛程，剔除实际未打的单场，不以赛前未知弃赛安排改动模拟。后续才公布的队员或组织名称不能提前用来建模。
5. 对主种子记录实际 5/10、三个栏共十格、选对八队数、晋级却错栏数、BO1/BO3 Brier 和对数损失。报告每个种子的同模型对照，Stage 3 按三届聚合，其他赛事分开。只有跨种子收益方向一致、与结构一致的独立赛事未出现明显退步、前三阶段的正式目标守住时才考虑替换默认。新加坡 Stage 1 原封存维持独立计分。后续 Stage 3 的参赛 16 队须待上一阶段结束方可封存。
