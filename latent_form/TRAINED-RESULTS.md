## 为什么布达佩斯的 FURIA 和 Spirit 没进全胜栏

两队均实际取得 3–0。按当时资料，推荐模型把 Falcons、Vitality 列在全胜栏，FURIA、Spirit 列在普通晋级；完整地图 ML 的栏位选择相同。推荐模型给 Falcons 的全胜概率为 28.50%，Vitality 为 22.27%。下表给出主种子 12,000 条独立审计路径中，六支实际全胜队的对应概率。

| 正式 Stage 3 | 实际 3–0 队 | 推荐的全胜率，独立 → 共享 | 地图 ML 的全胜率，独立 → 共享 |
|---|---|---:|---:|
| 奥斯汀 | FURIA | 4.43% → 4.56% | 3.43% → 3.48% |
| 奥斯汀 | Spirit | 30.38% → 30.38% | 34.65% → 34.75% |
| 布达佩斯 | FURIA | 17.55% → 17.55% | 23.93% → 23.93% |
| 布达佩斯 | Spirit | 11.43% → 11.43% | 14.21% → 14.21% |
| 科隆 | FURIA | 5.99% → 6.15% | 6.44% → 6.73% |
| 科隆 | Spirit | 24.47% → 24.66% | 70.60% → 70.01% |

布达佩斯开赛时可用的 3,411 对相邻 BO3 分属 164 项赛事。按同一届赛事统一聚类，胜负残差协方差为 −0.00294，赛事聚类 95% 区间为 −0.01841 到 0.01253。按预注册规则，状态尺度取零，两队预测逐路径保持一致。将 30 个审计种子汇合后，推荐模型的两队全胜概率为 16.85%、11.93%，地图 ML 为 23.49%、14.33%。在有正尺度的场地，哪支队处在好状态在赛前仍未知，各队的两种状态按相同概率抽取。[赛前训练数据](training.json) · [全体球队的实际战绩与概率](trained-summary.json)

## 单场胜率与尾部表现

每个场地的 120 种可能对阵都按四种状态重新居中，逐场 BO1、BO3 的赛前边际胜率守恒。18 个场地共 240 场实打 BO1、353 场实打 BO3。增加共享状态前后，推荐或外部 VRS 的 Brier 分别为 0.238198、0.223547，地图 ML 为 0.234369、0.207327；对应的对数损失也逐场地完全一致。18 个场地使用各自原有的单场矩阵；科隆 Stage 3 和外部场地为全 BO3，奥斯汀、布达佩斯 Stage 3 为混合赛制。EPL 的比分影响后续签位，条件胜率调整还逐项保留了赛前四种系列比分的边际概率。

三届正式 Stage 3 的两头平均 Brier 在主种子的推荐概率下为 0.111299→0.111116，地图 ML 为 0.093790→0.093643。对每队先合并 30 批审计路径，再按同一批实际球队评分，推荐为 0.111193→0.111116，地图 ML 为 0.093437→0.093400。两个指标取值越低越好。这些小幅变化与实际十格中够不够五格是不同的问题，在本轮没有增加正式 Stage 3 的主种子过关数。

Cluj 和 Bucharest 的训练协方差都为负，预先约定的算法自动取零，两个留出均未实际检验正尺度的收益。Bucharest 用二月榜还原种子、三月榜估计强弱，经重排可重放 33/33 场。地图 ML 在这届全 BO3 的 Brier 从 VRS 的 0.340898 降至 0.255745，整卡 4/10。它仍未过关。Elisa 春秋两届缺少完整且独立生成的 180 天训练窗口，结果文件交代这两项缺失。新加坡窗口只有 46 对相邻 BO3、8 项赛事，训练尺度为零，未计入实绩。[布加勒斯特资料](BUCHAREST.md) · [训练与缺失口径](TRAINING.md)
