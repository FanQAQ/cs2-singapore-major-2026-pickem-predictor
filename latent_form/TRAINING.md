# 赛前连续 BO3 的状态尺度

以下数值口径在读取相邻残差和估计值之前固定。每个目标只用其赛前 180 天 BO3。辅助 VRS 校准沿用已有实现，以 A 方积分差乘 `ln(10)/400` 为输入，逻辑回归无截距，斜率限制在 [0.05, 4]。损失是全窗所有实打系列对数损失之和加 2(b−1)²。一个系列只贡献一次，训练时排除 PGL Cluj-Napoca 2026 整届。[既有斜率与初始胜率](../tail_calibration/model.cjs) · [相邻场纳入条件](TRAINING-NEXT.md)

对同队视角计算连续两场的 `(胜负₁−p₁) × (胜负₂−p₂)`。先在同队同赛事内等权平均，再对该赛事各队等权平均，最后对所有赛事等权平均。赛事聚类区间用赛事均值的样本标准差除以赛事数平方根，并乘自由度为赛事数减一的双侧 95% Student t 分位数。区间仅描述这批赛事均值的离散程度。它以当窗辅助斜率为给定值，跨赛事反复登场的同一选手和不同目标间窗口重叠也会限制独立性。

每个球队符号独立取 ±1。同一球队一整个阶段共用其符号，概率只作用于 BO3。四种组合的两队状态差是 0、−2s、+2s、0。逐场反求常数 c，使四个条件概率平均恰为原 p。则该队正负状态的条件胜率差的一半是 `d(p,s)=[logistic(c+2s)−logistic(c−2s)]/4`。对不同对手，理论连续残差乘积为两场 d 的乘积。保持观测相同的三层权重，用二分反解 s。少于 40 对或少于 10 项赛事时设为零，协方差非正时也取零；估计超过上界时取 0.5。报告达到上限时仍未能解释的残差乘积，不用目标成绩挑参数。[完整预注册](PROTOCOL.md) · [生产状态积分](../engine/engine.js)

按同一届赛事合并各阶段后，三届 Stage 3 的 95% 区间都包含零。奥斯汀和科隆能在 0 至 .5 的范围内匹配各自的观测协方差。新加坡只有八项可确认赛事，未达到十项门槛。Cluj 和追加的 Bucharest 样本量足够，但各自点估计非正，因此外部两场的模拟会与基线相同。这两场可以检验零幅度能否准确还原基线，无法检验非零干预能否迁移。

两个端点都必须落在同一目标的赛前窗口。原赛程中可确定为同一届的阶段共享一个赛事权重，共有 105 对连续出场跨越不同的原阶段名称。整个已核实样本共 12,112 对，覆盖 685 届赛事。一个系列可给两边球队分别提供一次出场，也可与本队前后两场分别形成一对，因此相邻对数量可以超过独立系列数。完整输出记录了每个目标的 VRS 辅助斜率、最早和最晚观测日、分三/四/五人核心的数量、各类排除、逐赛事协方差及上限残差。追加的 Bucharest 窗不参与原 18 场的参数选择。[完整估值](training.json) · [BO3 观测行](../tail_calibration/training.json.gz) · [完整赛程与相邻对](adjacency.json.gz)

## 复算

```sh
python latent_form/training.py --math-only
python latent_form/training.py --check
```

需要 NumPy、SciPy 和 Node。第二条逐一核每对比赛在完整队伍出场序列里确实相邻，再从所有 12,804 场冻结原件重新筛出每个目标的时间窗。用项目既有 JavaScript 斜率与四状态引擎单独核对十九个辅助斜率、每窗观测协方差与模型理论协方差。数学自检另独立枚举同队加两名对手的八种状态，覆盖均值保持、反向对称、已知正尺度回收、零协方差边界、样本门槛和触顶。
