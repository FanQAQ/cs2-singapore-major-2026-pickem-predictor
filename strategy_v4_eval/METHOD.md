# 回合净胜与强弱校准策略回测

按网站相同的模型入口比较原版和新策略。原版使用 VRS 与按样本收缩的 BO1／BO3 修正。新策略同时使用校准后的近期表现、对强队表现、对弱队表现、对手实力校正后的回合净胜，并开启相同的赛制选项。模型在每届预测时都按当届赛前日期冻结。每种策略先模拟瑞士轮，再用实际对阵核对单场胜率和竞猜卡。

在项目根目录构建网站后运行下列命令。

```bash
node strategy_v4_eval/check.cjs
node strategy_v4_eval/check.cjs --check
node strategy_v4_eval/freeze.cjs --check
```

第一条命令复算 `report.json`，第二条核对逐项复现。报告包括五届首阶段的每届十格命中、三档命中分项、至少五格的届数、165 场胜负的 Brier 分数和对数损失。较低的 Brier 分数意味着预测概率整体离实际的 0／1 结果更近。以 33 场系列赛为一届、单独计算每届的赛果指标。

每次用 12,000 条路径搜索过关卡，再用独立的 12,000 条路径评价。固定随机种子 33719 对应网页推荐。对原版和新策略使用相同的另外 29 组随机数，再看两种策略的五届总命中和达标届数能变化多少。报告保留每组得分。这里的统计单位始终是五届不同的 Major。多组随机数可观察模拟选卡的稳定性。

另取奥斯汀、布达佩斯、科隆的 Stage 2／3 共 198 场作额外检验。参赛队和种子按各阶段确定，实力、回合统计与模型权重均固定在当届 Stage 1 前。全 BO3 阶段的每轮都使用 BO3 胜率。这六个阶段属于已发生的三届赛事，赛制及参赛构成与首阶段有差异。历史回测已参与过研究讨论，真正的赛前检验由封存后的新加坡赛事提供。

`freeze.cjs` 在北京时间 2026 年 11 月 21 日可独占创建一次新加坡赛前文件。它保存十格推荐、各队结局概率、两种赛制对阵胜率、日期、模拟设置及输入和运行代码的 SHA-256。检查命令只读。文件名为 `forecast_archive/singapore-stage1-v4-2026-11-21.json`。
