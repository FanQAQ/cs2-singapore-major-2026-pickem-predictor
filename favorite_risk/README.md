# 四支热门会有几支出局

2026-11-21 赛前研究。先按已经发布的推荐模型和固定的 24,000 条路径，从晋级概率最高的四队中观察整届是否至少一队或两队未晋级。同概率按官方种子排序。另用官方种子前四重复计算。只在已完赛首阶段核对结果。用同一届内各队在同一条瑞士轮路径的战绩计数。

按本项目赛前矩阵逐轮调用生产配对和 BO1/BO3 规则。用生产随机数的两组路径逐队核对全部 64 个战绩频率，然后固定热门名单与十格卡，用另外四组种子各模拟 10,000 次。报告同时记录在该届实际命中格数或以下的模拟比例。赛后能看到哪些队失手，赛前能估计此类情形发生的概率。六届各自独立计算，此项研究不改变默认模型、十格卡和历史评分分母。

从项目根目录运行 `node favorite_risk/run.cjs --check` 复核 `report.json`。蒙特卡洛误差只衡量给定模型时的抽样误差，模型可能高估或低估真实风险。

科隆的 GamerLegion、BetBoom、B8 和 BIG 是推荐模型的晋级前四，四队都晋级。用官方种子前四核对，HEROIC 出局，它在模型里的赛前晋级概率为 53.7%。原样重放科隆时，已选十格卡取得 4 格或更少的概率为 61.7%。

新加坡的模型前四为 Ninjas in Pyjamas、Eternal Fire、HEROIC、PARIVISION。四万条新路径中，有 79.8% 至少一支出局，34.1% 至少两支出局。四组种子分别得到 79.4%、79.5%、80.1%、80.2% 的至少一队出局概率。阶段尚无真实赛果。
