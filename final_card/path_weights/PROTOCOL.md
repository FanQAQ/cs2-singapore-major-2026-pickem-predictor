# 用晋级途径校准完整瑞士轮路径，再按五格目标选卡

既有 Stage 3 分组卡把直邀组与晋级组的历史频率混合进每队四类战绩，选出期望格数最高的卡。本次保持其先验、原胜率和实际对阵规则，检验整张卡达到五格的目标。预选三届旧 Stage 3，以及以前已知分组卡在其中一场退步的 EPL S22、S23 第二阶段。五个场地均为开发或复用对照。

先复用 3 组种子、每组 2,000 条路径。每条路径是完整合法的瑞士轮终局。用广义迭代缩放把模拟分布向相同的分组目标移动，最多 32 次，每步将 16 支队的对数频率修正取平均。只接受有效样本量至少为原样本一半的更新，避免少数模拟终局主导。选卡以默认卡、未加权的过关卡、原分组卡和校准后最高期望卡为起点，在合法的两队换位中最大化加权过关频率。只在严格提高时接受换位；分数相同时保留原方案。独立的未校准 4,000 条路径给每张卡核分，登记真实过关和三档命中。原分组期望、加权期望、加权过关分列，以区分分布变化和选卡目标。

固定主种子必须在三届正式 Stage 3 过两届，且主种子在两场 EPL 都不能把原先过关的卡改成未过。只有通过上述初筛才扩到例行预算和多组种子；不调整有效样本下限、迭代次数或重新选择主种子。
