# 各地区完整 VRS 榜与全球分布

本目录采集同日的全部榜单席位，用于回答「本地区排在前列的球队，在全球处于什么水平」。42 期官方榜包含 126 张地区榜。2024 年 8 月 6 日起另有 28 张同日全球榜。原始日期与 `region_risk/evidence.csv.gz` 的 2,894 场非 Major 线下赛记录逐场匹配，所有取数日期均早于对应比赛。2,488 场可匹配正式全球榜。

## 口径

- 地区上榜总数取整张官方地区榜。Valve 公布的部分低位阵容少于五人，作为一个实际公布的排行榜席位计入。比赛归属仍由比赛模型独立核对实际五人与积分阵容。
- 地区前十中位积分取地区榜第 5、6 名的积分平均值。保留地区前 11 队的当时阵容、名次和积分，供模型剔除双方各自队伍后重新计算前十。全榜中位数同时可查。不同地区上榜队伍数不同，尤其长的榜会包含更多低积分队，两个中位数的含义不同。
- 全球前 10、30、50 的地区席位按全球榜的原始实际名次计算，用当期同一套阵容精确连接地区榜。所有全球席位均能匹配相应地区，积分也逐队相同。对同一全球阵容同时列入两个地区榜的情形，将其全球席位按地区等分，使三地合计恰好等于全球前 K 队。上海和奥斯汀当年的 Liquid 均发生这一情况。原始地区队数仍按各榜实际登载计。
- 哥本哈根仅能取到三张地区榜，展示三区发布积分及地区前十的中位值。保留全球总数、全球名次和全球前 K 席位为空。此时缺少统一全球参照，模型跳过这类日期的赛区深度特征。
- 每届 Major 使用与基础实力模型相同日期的官方榜（新加坡为 2026-11-02）。当月完整非正式排名或后续临赛估算有不同数据口径。全球席位和地区队数用于说明排名分布；分布本身无法区分地区比赛强度、赛历结构与球队争取积分的动机。

## 冻结资料与复算

`tables.json.gz` 保留官方整榜逐行数据，每条为积分、当时队名和大小写规范化的出场名册，数组位置加一为正式排名。`sources.json` 保存逐表固定版本链接、原始 Markdown 的 SHA-256、行数。早期根目录文件使用发布当期 commit，月榜使用同一固定 Git 修订的对应日期邀请榜。各地区完整五人行的规范化散列同时与既有地区模型的 126 份原始指纹核对。资料来源为 [Valve 官方榜单仓库](https://github.com/ValveSoftware/counter-strike_regional_standings)。

从冻结整榜脱网核对 42 期数据、新加坡及五届历史 Major 的六份阶段数据与按时点匹配，请在项目根目录执行：

```sh
python3 region_vrs_data/build.py --check
python3 region_vrs_data/check.py
```

如需从已固定的 Git 修订重新下载并逐表校验，运行 `python3 region_vrs_data/prepare.py --fetch --check`。已有原始 Markdown 时也可使用 `--tables 目录1 目录2`。之后运行 `python3 region_vrs_data/build.py` 可重建网站用输入。
