# 相近对手线下表现

这个候选项估计同一核心在近期线下比赛中，面对与当前对手难度相近的对手时，能否继续超出当时双方积分给出的预期。它保留比赛日期、赛制和实际阵容，允许参考同赛区或跨区 LAN。

## 样本及时间

资料来自本项目冻结的 region_risk/evidence.csv.gz 和 refresh_close/observations.json.gz。额外比赛需要回查公开归档中的 LAN 场地标记，核过的场次列于 late_venues.json。两库按 HLTV 场次 ID 去重。两侧都需有实际比赛阵容，并与该日之前发布的 Valve 计分阵容至少重合三人。歧义昵称采用既有身份库的规则。同一份历史在不同目标队中均按选手归属，可以跨俱乐部继承。线上赛及 Major 正赛排除。场地已核实的赛前 RMR 可计入，其中上海的资格赛覆盖 53 场。不同来源合并后有 2,959 场可核实系列赛。每届只取其赛前截止日及以前的行，训练和实际预测均执行按日期筛选。

单队取截止时点前 120 天的 BO1 和 BO3。每场的基础预期为 p = 1/(1+10^(−双方 VRS 分差/400))。基础权重取 45 天半衰期，再乘上留队人数占五人的比例平方。对手难度按球队打这场比赛的预期胜率衡量，新旧两场的胜率越接近，历史成绩的权重越高，采用带宽 0.18 的高斯权重。赛制不同的观察再乘 0.35。只有一场或没有历史时，该队修正取零。

用加权胜负减预期的总和除以 2 + 加权 p(1−p) 之和。2 是固定先验，在 p=0.5 时相当于八场中性比赛，避免少数冷门主导结果。分别计算双方在各自赛前胜率下的结果，再取差。每届用之前 365 天的 LAN 对局拟合一个非负正则化系数，拟合目标是相对于各场自身赛前积分概率的增量。每个训练样本使用档案中该赛事首场日之前的历史，同场赛事各轮成绩都不互相引用。长赛事的训练权重最多为 12 场，每届系数独立估计，加入对数胜算的最终调整限制在 ±0.45。应用到网页当前所选基础模型后的实际收益另外由逐届 Major 回测检验。归档覆盖不均，科隆样本最晚仅到 2026 年 3 月 23 日。缺少证据的一侧固定为零。

项目根目录下运行以下检查。最后一条只在需要从固定原始归档复核 LAN 场地时使用。

```sh
python lan_signal/build.py --check
python -m unittest lan_signal.test_signal
node lan_signal/check.cjs
python lan_signal/prepare.py /path/to/results.json.gz /path/to/griffin/archive --check
```
