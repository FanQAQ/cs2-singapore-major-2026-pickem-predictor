# 临赛综合策略的五届对照

在相同的参赛阵容、瑞士轮配对、BO1／BO3 规则和历史赛果下，比较五种预先固定的设置。基线为「近期表现模型」的原快捷策略。三种单项试验分别只打开临赛战绩、跨区校正、稳健选卡。综合策略同时打开以上三项。每套设置均报告 0–3 两步风险排名。风险分解本身是观察量，不改变任何单场胜率。模拟禁选图和临赛积分估算继续作为独立选项；当前对照保持该两项关闭。

每届 Stage 1 首日之前冻结输入，按 120 种潜在对阵计算两种赛制的胜率，用模拟路径选出 2/6/2 的十格卡。先用 12,000 条路径生成「过关率优先」和「最高期望命中」两张候选。开启稳健选卡时，只有候选不同才用额外 12,000 条路径对两张卡配对比较。原有独立 12,000 条路径用于为最终选中的卡估计过关率。五届 165 场的真实结果只用于评分。各届冻结时点、实际新增系列赛数量、受影响的队伍数量均单列。

0–3 排名由同一批原始模拟路径的全败概率递减得到，相同概率按初始种子升序。分母是所有路径，实际两连败后再输第三场的条件概率只使用进入 0–2 组的路径。每一届真实有两支全败队伍，统计其中几支出现在赛前前二、前四及前六。直接取赛事最后两号种子是另一个预设对照。tailQuality 分别在全部参赛席位上评估两连败和最终全败的 Brier 分数，并仅对真实走到 0–2 的队伍评分其淘汰战条件败率。另逐场计算概率的 Brier 分数和对数损失（两者均越低越好），使用赛前预测胜方的正确场数作为附加指标。主表的单场概率为赛前冻结的两两胜率。若时点验证支持共享阶段状态，另外用每轮开打前、仅以此前完整轮次的结果更新各队状态，并单列 afterPriorRounds 评分。整卡和风险排名始终按锁卡前无已知结果的路径计算。

正式卡使用原有种子 33719。重复使用该项目已经确定的 30 个种子，在相同五届赛事上评估填卡对模拟随机性的敏感程度，统计平均过关届数、平均总命中、比同随机数下的原卡多过关／持平／少过关各几次。固定种子卡和各个种子的命中均与旧档交叉核验。

三届赛事的六个后续阶段（198 场）额外比较原卡与稳健选卡。使用各阶段已知的参赛队与种子、所属 Stage 1 前冻结的实力、真实赛制；科隆 Stage 3 全程 BO3。后续阶段的阵容和对手与首阶段不同，没有将首阶段的临赛输入或区域修正套用到后续队伍。该部分使用固定的原有随机数。五届首阶段与这六个后续阶段均为历史重建，过关届数不等于未来一届的过关概率。

在项目根目录构建网站后运行命令。

```sh
node integrated_eval/check.cjs --check
node integrated_eval/freeze.cjs --check
```

第一条核对两份文件。report.json 是网页使用的逐届与汇总评分，diagnostics.json 提供真实对阵的逐场胜率、各队三档概率、两步风险、候选卡及裁决依据，以及每个模拟种子的实际命中数。去掉 --check 可重新生成历史报告。第二条只读复核在 2026 年 11 月 21 日封存的新加坡临赛综合预测。新加坡尚未开赛，记录包含 16 支队伍各自的风险分解和对手分布、两种赛制的完整矩阵，以及模型输入、实现和选卡比较的 SHA-256。封存创建只允许在记录日期执行一次。
