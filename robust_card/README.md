# 两张候选卡的稳健比较

在每个历史阶段、每种胜率模型和每组已锁定的赛果下，按当场瑞士轮规则生成完整比赛路径。每张卡都占用 2 个全胜格、6 个普通晋级格和 2 个全败格，至少中 5 格即达标。

1. **生成候选卡。** 沿用网站原有的 12,000 条选卡路径。“最高期望命中”在十格约束下最大化各格预测命中概率的总和。“过关率优先”搜索能在更多路径下达到五格的填法。两张卡的生成方法和既有随机数序列均可按原设定复现。
2. **决定展示哪张。** 两张卡相同时，直接采用该卡，无需比较。两张卡不同时，另用 12,000 条独立路径，让它们逐条同场计分。每条路径记一个差值 D：仅过关率优先卡达标计 +1，仅最高期望卡达标计 −1，其余计 0。D 的均值就是两张卡的过关概率之差。只有双侧 95% 区间的下界大于零时才采用过关率优先卡，其他情况保留最高期望命中卡。这个保守规则在本轮回测前固定。
3. **报告过关率。** 选定后使用网站原有、另外独立的 12,000 条评价路径给这张卡评分。比较时用过的计数只用来解释选择。页面上的整卡过关率、期望格数和命中直方图均由独立评价路径生成。故两张卡不同时一共 36,000 条路径，相同时为 24,000 条。调低模拟预算时，比较路径数随独立评价路径等比例调整。

区间使用经验 Bernstein 界。设 n 为比较路径数，s² 为配对差值的无偏样本方差，则 95% 区间的半宽为 sqrt(2s² log(80) / n) + 14 log(80) / [3(n−1)]。估计区间与 [−1,1] 取交集。这个区间反映指定胜率模型及已有锁定结果下的蒙特卡洛抽样误差。跨赛事预测能力另外用各届真实赛果检验。理论依据为 Maurer 和 Pontil 的定理 4，对区间长度为 2 的随机变量作线性变换，并合并两侧边界。[Empirical Bernstein Bounds and Sample Variance Penalization](https://www.cs.mcgill.ca/~colt2009/papers/012.pdf)

在项目根目录运行 `node robust_card/check.cjs` 可复核两卡相同、数值近似持平、优势明显及整届锁定等情况。浏览器先载入 engine，再载入 robust.js。对同一基础模拟调用 `PickRobust.apply(sim, matrix, seed, locks)` 可取回选定卡、原过关率优先卡和配对比较数据。所有概率差与区间使用 0–1 量纲。
