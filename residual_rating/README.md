# 用三人核心联合估计对手实力

**结论：保留原推荐。** 新模型改善了五届首阶段 BO1 和 BO3 的胜率误差，实际十格卡少中两格。30 组配对随机种子中，25 组的过关届数下降。上海与科隆在发布种子下仍分别为 3/10 和 4/10。

## 赛前确定的实验

问题是某队超出 VRS 预期的战绩，能否通过整张对手网络识别出稳定实力。已有 `model_v3` 根据比赛先后按固定步长更新一次预测误差。本次对每届赛前窗口内的所有对局联合求解带收缩的 Bradley–Terry 模型。多支对手反复交手时，一方表现与其他对手的比赛一起决定其估计值。

每场的线性预测量由赛前 VRS 分差（每 100 分）乘一个共同斜率，加上两套出场阵容的残差实力之差组成。每套五人有 10 个三人组合，阵容残差等于它们的系数和除以 √10。两套阵容直接共享 3、4、5 人时，对应共享 1、4、10 个组合。未在该场上阵的选手无法为该场创造组合。没有三人历史核心的阵容残差为零。每个三人组合使用零均值、标准差 0.5 的独立正态先验，由于除以 √10，完整五人组合的先验标准差也是 0.5 logit。

窗口固定为截至原模型快照当日的 90 个自然日，场次权重按 45 天半衰期衰减。历史每场使用其当时可得的 VRS 分差与实际登场五人。VRS 共同斜率向原项目初始值 log(10)/4 收缩，正则强度为 1。它仅帮助拟合对手网络，输出到网站胜率矩阵的只有三人组合残差。昵称沿用已有归一化规则。

预测时关闭原推荐模型的近期胜负、对强队表现和对弱队表现三项，用该配置原先拟合的 VRS 与回合净胜、赛制及赛区修正生成概率，再加双方网络残差的 logit 差。这样每场只使用一套近期胜负修正。窗口、先验尺度和替换范围在评分之前选定；本轮只试这一组。上海淘汰阶段的对局与成绩未进入实验。
