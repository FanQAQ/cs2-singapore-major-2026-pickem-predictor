# 首发连续性的逐届增量检验

同一俱乐部更换五人后沿用旧成绩、跨俱乐部整队转会丢失成绩，均已由 V4 原有的三人核心匹配处理。本实验检验另一个问题：在已有这些保护和回合表现的基础上，这支五人阵容此前共同出场的程度，能否进一步预测胜负。

固定 V4 的单场模型、赛制处理以及瑞士轮和选卡算法。对每支目标队取近 90 天、与目标五人有三人及以上重合的已验证系列赛。三人、四人和五人重合分别记为 −1、0 和 +1，以 45 天为半衰期加权求均值，在分母加入五场中性比赛。两队都能找到历史时，将两队该指标的差值乘以单个系数，加到对局的对数胜算上。任何一方缺少历史时，沿用 V4 的胜率。

按每届 Major 单独训练，先从赛前冻结的 85 天训练集还原 V4 的基础对数胜算，再保持基础模型参数固定，拟合一个零均值、标准差为 1 的正态先验约束下的连续性系数。同一天的比赛统一计算历史特征后才写入赛果。训练使用合并赛制的基础模型估计增量，评价阶段将同一增量应用到生产环境的 BO1 和 BO3 概率。比赛使用当次赛前公布的首发，跨俱乐部按选手匹配。该实验使用能同时匹配阵容和 VRS 的公开历史子集。

使用五届首阶段的全部 165 场实际对局验证。80 个参赛席位中 79 个具有近期阵容历史，162 场的两队都有历史。平均 Brier 分数由 0.22976 降至 0.22829，对数损失由 0.64958 降至 0.64640。改善主要来自奥斯汀，排除该届后其余四届的平均 Brier 略高。每届实际卡片命中数均与 V4 相同，固定随机种子下都是五届中两届过关。

`report.json` 包含逐届 Brier、对数损失、双方均有历史的场数、训练场数、拟合系数及实际卡片分数。训练仅读取冻结的赛前比赛和首发。从项目根目录运行以下命令，须 Python、NumPy、SciPy 和 Node.js。

```sh
OPENBLAS_NUM_THREADS=1 python research_lineup/fit.py --check
```
