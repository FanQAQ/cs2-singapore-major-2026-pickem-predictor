# Major 超预期表现的检验

从五届首阶段和六个后续瑞士阶段实际开赛前的资料出发，分别比较三种设置。

- 基线使用不加 Major 表现修正的赛前实力。五届 Stage 1 采用网站当前的「近期表现＋赛区实力」。六个后续阶段沿用该项目已封存的 V4 模型，使用各阶段的参赛阵容与种子，实力资料截止于该届 Major 开赛前。
- 上线设置只在先前已结束的整届 Major 提供足够验证证据时调整胜率。联赛实力、地图、选卡方式和模拟种子与基线一致。
- 离线试算保留相同的阵容匹配、至少两届历史、大赛超预期表现估计和收缩权重，只跳过以往整届的效果检验。它用于辨别「候选特征是否有增益」与「当前开关是否生效」。

每届进入当前赛事后的赛果只用于评分。以当年阶段赛制重放真实对阵，记录胜方命中数、Brier、对数损失，以及三种概率相对基线实际改变的比赛数。informative 单列离线试算有可测胜率变化的对阵。每届全赛场的球队都是实际对手，Brier 和对数损失越低越好。

每套胜率还会重跑完整瑞士轮，比较只选一张 2／6／2 卡时的三区命中和过关届数，并查验全败风险排名。五届首阶段使用同一组 30 个随机种子，每组 24,000 条模拟路径；重复种子改变的是蒙特卡洛抽样，五届真实赛果不变。若矩阵和选卡方法与旧封存一致，核对生产种子的全部队伍概率、卡及矩阵后直接复用审计过的其余 29 个种子的成绩。六个后续阶段的 198 场作为补充按固定种子评估。它们来自三届已经计入首阶段对照的 Major；分别评分能检查迁移到更深轮次的表现，统计独立赛事数仍以整届计。同届较早阶段的赛果不进入后续阶段的特征或启用条件。

五届首阶段中，哥本哈根、上海和奥斯汀的阵容均无满足两届先前记录的核心，布达佩斯和科隆分别有 1、5 队满足。现行规则在这五届及新加坡均保留基线概率。离线试算在 165 场中改变 25 场，Brier 从 0.22722 到 0.22675，固定种子成绩从 23/50 到 22/50，两个版本均有三届过关且全败均为 2/10。30 组随机数全部与相同种子的基线有相同过关届数。在另六个阶段，离线试算有 63/198 场改变胜率，Brier 从 0.23773 到 0.23966，固定种子从 21/60、1/6 阶段过关变为 24/60、2/6 阶段过关。先前阶段和后续阶段的单场概率、固定种子选卡改善方向均不一致。

新加坡 16 个首发五人中，10 队有可计入的历史，4 队跨至少两届。此前两届可评估该特征的 88 场对局中，Brier 从 0.21372 到 0.21716。新加坡保留现有赛区策略的赛前概率，完整排名版封存也适用于本次推荐。

汇总及逐届计分在 report.json，首阶段逐场输入、模型选位、模拟种子和对应成绩在 diagnostics.json。建好网站后运行下列命令。

```sh
node major_form_eval/check.cjs --check
node major_form_eval/freeze.cjs --check
```

第一条从当前网站运行逻辑核对回测。第二条核对新加坡赛前推荐和整套概率。若开关完全复现原赛区策略，复核此前封存的赛区版预测；若有区别，独立的赛前封存包含新加坡的阵容、输入依据、概率、卡片、实现哈希和旧版封存哈希。
